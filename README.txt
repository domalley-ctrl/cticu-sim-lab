ICU Sim Lab: installable web app

Put this whole folder on any free static host (GitHub Pages, Netlify Drop, Cloudflare Pages).
It must be served over https for install and offline to work.

Install:
  iPhone/iPad (Safari): open the site > Share > Add to Home Screen.
  Android (Chrome): open the site > menu > Install app.
  Mac/Windows (Chrome or Edge): install icon in the address bar.

After the first visit it works offline. Progress is saved on that device.
